# Dar Zayna

Client website for Dar Zayna, with a separate frontend and backend.

## Status

See the Dar Zayna section of [PROJECTS.md](../PROJECTS.md).

## Folders

- `frontend/`: the website the visitors use.
- `backend/`: the API, database and admin logic.
- `assets/`: logos, photos, fonts and files supplied by the client.
- `tests/`: tests for the frontend and the backend.
